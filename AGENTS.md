# Repository Instructions

## Git workflow

- Always use Conventional Commits.
- Choose an appropriate commit type, such as `feat`, `fix`, `refactor`, `test`, `docs`, `chore`, or `perf`.
- Write concise, imperative commit subjects.
- Use a dedicated feature branch for each substantial improvement.
- Do not commit substantial feature work directly to `main`.
- Run relevant tests and skill validation before merging.
- Use a Conventional Commit message for merge commits created locally.
- Delete merged feature branches locally and remotely after verifying the merge.
